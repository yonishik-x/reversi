# Reversi / オセロ

1枚のHTMLで動くオセロ（リバーシ）です。

## 遊び方

公開ページを開くだけで遊べます。

- 1人で対戦：あなた＝黒、CPU＝白（弱い／普通／強い）
- 2人で対戦：同じ画面で交互に打つ
- 置ける場所は半透明の丸で表示
- 裏返る石はマスが黄色く光り、置いた場所に近い順に1個ずつ大きくひっくり返るアニメーション
- ハンディ：黒の石を四隅に1〜4個、最初から置いて開始できる
- パス・終局・勝敗判定、待った、最初から、に対応
